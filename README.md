# 🎯 Windy Bubble Shooter

Windy Bubble Shooter is een browser-based bubble shooter game waarin de speler gekleurde bubbels moet afschieten om combinaties van drie of meer dezelfde kleuren te maken. Door combinaties te maken verdwijnen de bubbels en verdient de speler punten.

De game is ontwikkeld als onderdeel van een schoolproject, waarbij onderzoek, design, ontwikkeling en het testen van een interactieve webgame centraal staan.

## 🎮 Gameplay

De speler bestuurt een shooter onderaan het scherm. Vanuit deze shooter wordt een bubbel afgeschoten richting het speelveld.

Het doel is om:

* 🎯 Bubbels van dezelfde kleur te combineren
* 💥 Combinaties van drie of meer bubbels te maken
* ⭐ Zo veel mogelijk punten te behalen
* 🏆 Een zo hoog mogelijke score neer te zetten
* ❤️ Te voorkomen dat de bubbels de onderkant van het speelveld bereiken

Door strategisch te schieten kunnen grotere combinaties worden gemaakt en kunnen meerdere bubbels tegelijkertijd verdwijnen.

## 🚀 Installatie

Omdat Windy Bubble Shooter een webgame is, zijn er geen complexe installatiestappen nodig.

### 1. Repository clonen

```bash
git clone https://github.com/USERNAME/windy-bubble-shooter.git
```

### 2. Ga naar de projectmap

```bash
cd windy-bubble-shooter
```

### 3. Start de game

Open `index.html` in een webbrowser.

Wanneer het project gebruikmaakt van een lokale development server, kan bijvoorbeeld **Live Server** in Visual Studio Code worden gebruikt.
